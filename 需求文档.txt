# 项目命名建议

## 主推：**聚匣 / GatherBox**

| 项 | 内容 |
|---|---|
| 中文名 | 聚匣 |
| 英文名 | GatherBox |
| 寓意 | **聚** = 汇集多方文件；**匣** = 小巧收纳盒，有质感不土气 |
| 分发物命名 | `GatherBox.exe` / `cloudflared.exe` / `GatherBox.apk` |
| 项目目录 | `gatherbox/` |
| 适用性 | 两个字好记，中英文都直白描述功能，适合印在 exe 标题栏和 APK 图标下方 |

## 备选

| 中文 | 英文 | 侧重 |
|---|---|---|
| 投递箱 | DropBin | 强调"投"，直白简单 |
| 轻收 | LiteCollect | 强调轻量、随手 |
| 文件驿站 | FileStage | 强调中转、短暂停留 |
| 直达投递 | DirectDrop | 呼应"分享页直接上传"特色 |
| 拾匣 | PickCase | 谐音"十匣"，拾取之意 |

## 选择建议

- **想稳、想直白** → 选 **投递箱 / DropBin**
- **想要点气质** → 选 **聚匣 / GatherBox**（推荐）
- **想突出分享直接上传** → 选 **直达投递 / DirectDrop**

# 文件收集站 · 精简需求文档

## 一、技术栈

| 类别 | 选型 |
|---|---|
| 运行时 | Node.js 20.x LTS |
| Web 框架 | Express 4.x |
| 文件上传 | Multer |
| 前端 | 原生 HTML + CSS + JavaScript（无框架） |
| 打包工具 | nexe（打包为 Windows 单文件 exe） |
| 公网隧道 | cloudflared（Quick Tunnel / TryCloudflare） |
| 分发物 | `FileCollector.exe` + `cloudflared.exe`（同目录） |

## 二、需要实现的功能

1. **本地 Web 服务**：双击 exe 启动服务，默认端口 3456，自动打开/提示 `http://localhost:3456`。
2. **局域网访问**：绑定 `0.0.0.0`，启动时打印本机所有局域网 IP 地址，同网段设备可通过 `http://<IP>:<端口>` 访问。
3. **文件上传**：支持拖拽 + 点击选择，多文件上传，显示上传进度条，文件存储到本地 `uploads/` 目录。
4. **文件管理**：记录原始文件名、大小、上传时间等元数据；提供文件列表页，支持下载和删除。
5. **CF 快速隧道**：一键启动 `cloudflared tunnel --url http://localhost:<端口>`，解析并显示公网 URL（`*.trycloudflare.com`），支持停止隧道；exe 退出时自动清理 cloudflared 进程。
6. **单文件分发**：用户拿到 exe（及伴随的 cloudflared.exe）双击即用，无需安装 Node.js 或 cloudflared。

## 三、追加功能

### 7. 打包 WebView APK

| 项 | 说明 |
|---|---|
| 目标 | 生成一个 Android APK，内置 WebView 加载文件收集站的前端页面 |
| 打包方式 | 使用 **Capacitor**（或现成的 HTML→APK 工具）将现有 web 页面封装为原生 WebView 壳 |
| 加载内容 | 加载本机 `http://<局域网IP>:<端口>` 或 CF Tunnel 公网 URL（启动时可通过配置/输入指定） |
| **必须实现** | **重写 `WebChromeClient.onShowFileChooser`**，否则 WebView 内 `<input type="file">` 无法唤起文件选择器 |
| 权限 | 申请存储读取权限（适配 Android 11+ 分区存储） |
| 产物 | 一个可安装的 `.apk`，与 `FileCollector.exe` 并列作为分发物 |

**关键限制：** 标准 WebView 默认不支持 H5 文件上传，必须由原生代码介入实现 `onShowFileChooser` 回调，纯前端无法绕过。如果选用现成打包工具（如 web-to-app、html2apk），需确认其已内置该回调；否则需基于 Capacitor 自行添加原生代码。

### 8. 分享页直接跳转上传

| 项 | 说明 |
|---|---|
| 目标 | 用户打开分享链接后，**不经过首页，直接进入上传界面** |
| 实现方式 | URL 参数驱动：`http://<host>:<port>/?mode=upload` 或 `/upload?share=<token>` |
| 前端行为 | 页面加载时解析 `URLSearchParams`，若 `mode=upload` 则隐藏首页内容、直接展示拖拽/选择上传区域 |
| WebView APK 配合 | APK 启动时默认加载带 `?mode=upload` 的 URL，实现“打开 App 即上传” |
| CF Tunnel 配合 | 启动隧道后，除了输出根 URL，同时输出 `?mode=upload` 的**分享专用 URL**，供公网用户直接使用 |
| 可选扩展 | 支持 `?to=<子目录>` 参数，将文件上传到指定子目录，便于区分不同分享来源 |

**URL 参数约定：**

```
/                        → 完整页面（上传 + 文件列表）
/?mode=upload            → 只显示上传界面，适合作为分享链接
/?mode=upload&to=xxx     → 上传到 uploads/xxx/ 子目录
```
